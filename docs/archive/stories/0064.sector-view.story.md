## Sector View (MySector)

The Sector View (`MySector.aspx`) provides a tactical overview of a player's local galactic neighborhood (or any queried sector in the universe). It acts as the primary hub for neighborhood intelligence, threat assessment, targeting, diplomacy, and sector coordination.

### Galaxy and Sector Structure

- The game universe is partitioned into coordinates: **Galaxy : Sector** (e.g., `1:9` indicates Universe 1, Sector 9; `1:1` is Sector 1).
- Each sector contains a group of kingdoms (typically 5 to 20 kingdoms consisting of active players, newbie kingdoms, inactive food kingdoms, and bot AI kingdoms).
- Sector 1 (`1:1`) often serves as a dedicated bot/food sector (`FOOD` status) where inactive or practice targets reside.
- Regular PvP sectors distribute active players and AI bots evenly based on land/networth brackets.

---

### Header and Sector Navigation

At the top of the sector view, players have navigation controls and sector identity information:

1. **Navigation Toolbar:**
   - **Home (House icon):** Instantly returns the player to their own home sector.
   - **Previous Sector (`<<`):** Navigates to `Sector - 1` (minimum Sector 1).
   - **Sector Jump Input:** An input box (`SECTOR [ N ] [ Go ]`) allowing players to jump directly to any sector number.
   - **Next Sector (`>>`):** Navigates to `Sector + 1`.
   - **Paging / Last Sector (`?last=true`):** Query parameter navigation that jumps directly to the highest-numbered populated sector in the universe.
   - **Favorite Sectors (Star icon):** Players can star up to 3 sectors to pin them beneath the navigation bar for 1-click access.

2. **Sector Banner & Details:**
   - **Sector Title:** Displays the sector name and galactic coordinates (e.g., `Welcome to Star Kingdoms (1:9)` or `I Am Food (1:1)`).
   - **Panoramic Banner:** Thematic space landscape artwork representing the sector's star system.
   - **Sector Message / MotD:** An announcement or description text displayed beneath the banner (e.g. alliance recruitment links, discord links, or sector directives set by the sector ruler/president).

### Kingdoms Table

The main section displays a table of all kingdoms located in the sector.

#### Table Columns

| Column | Description |
|---|---|
| **Status** | Status indicators: online/active status (green lightning / red power icon), combat status (`Won · 0`, `Hit · 56`), and protection mode badges (`Newbie (39)`, `PvE`, `FOOD`). |
| **Alliance** | Kingdom's alliance tag in brackets (e.g. `[Jolt]`, `[Halloween]`). Links to Alliance Info. Displays **War** badge if at war, or **Grace** badge (48-tick post-war protection). |
| **Relics** | Number of galactic relics held by the kingdom (e.g. `3 ★`), or blank if none. |
| **Kingdom Name** | Name of the kingdom, linking to its Kingdom Profile. The player's own kingdom is visually marked (e.g. `@` suffix or highlighted row). |
| **Planet Type** | Planet environment (e.g. `Ice Giant`, `Helium`, `Mystical Lands`, `Desert Wasteland`, `Shadow Lands`, `Albion Prime`). Hovering displays planet traits/modifiers. |
| **Race** | Race and level (e.g. `Gistrami Lvl 1`, `Terran Lvl 1`, `Ancients Lvl 2`). Hovering displays racial traits/bonuses. |
| **Land** | Acreage of the kingdom. Shows net land change over recent ticks (e.g. `↑20`). Clicking links to universal land rankings. |
| **Networth** | Total networth of the kingdom. Shows networth change over recent ticks (e.g. `↑1,015` green, `↓698` red). Clicking links to networth rankings. |
| **Honor** | Military honor points accumulated through combat (e.g. `1,000`, `1,635`). |
| **Land Gain** | Estimated land acres that would be gained by the viewer upon a successful military conquest against this kingdom. |
| **Return Time** | Estimated travel and recovery time (in ticks) for the viewer's military fleet if an attack is launched against this target. |
| **Last Hit** | Attack history between viewer and target: displays ticks elapsed since last attack and outcome (e.g. `Hit · 37`, `Won · 0`). |
| **Last Probe** | *(Optional/Custom column)* Ticks elapsed since the viewer last performed an espionage probe against this target. |
| **Actions** | Quick-action button bar containing direct operational links (see below). |

---

### Direct Kingdom Actions

Each row in the table provides 5 quick-action buttons for instantaneous operations without manual target lookup:

1. **Probe / Espionage (`🔍`):** Navigates to `Probe.aspx?kdID=<id>` with target pre-selected for covert operations (spying, sabotaging, robbing).
2. **Military Attack (`🎯`):** Navigates to `Attack.aspx?kdID=<id>` with target pre-selected for military assault.
3. **Missile Launch (`🚀`):** Navigates to `Missile.aspx?kdID=<id>` with target pre-selected for nuclear/chemical/conventional missile strikes.
4. **Send Message (`💬`):** Navigates to `MailRoom.aspx` / compose message addressed to the kingdom's ruler.
5. **Kingdom Notes (`📋` / `#`):** Opens a personal notes popover/modal allowing the player to view and save private intelligence notes, threat warnings, or reminders regarding this specific target.

---

### Sector Summary Footer

At the bottom of the sector table, summary pills display aggregate metrics for the sector:

- **📈 Networth:** Sum total networth of all kingdoms residing in the sector (e.g. `647,908`).
- **🌐 Land:** Sum total land acres possessed by all kingdoms in the sector (e.g. `6,035`).
- **👥 Kingdoms:** Total number of kingdoms currently present in the sector (e.g. `7`).
