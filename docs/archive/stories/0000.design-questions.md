## Game mechanics/design questions
Compared to the OG game, we want to improve a few things.

### How to make newbie mode more accessible to trully new players?
96 ticks of self ticking seems a lot. So we want to change that.

Resolution:
- Make it 8 steps process when each tick is 16 ticks worth
- Longer effective newbie mode should allow broader range of different strategies to be viable.
- 8x16 isn't set into stone, we can adjust that.

### How do we teach players of game mechanics?

Resolution:
- We want PvE mode to extend effective newbie mode for about 72 hours.
- During PvE mode, we spawn bots for players to attack, this way they can learn combat mechanics in a safe environment.
- During Newbie mode we prevent advancing each step if they don't meet some minimum criteria, e.g. by step 4 have x scientists or y defense queued at step 7.

### Why to change exploration mechanics?

Proposed exploration mechanics would automatically explore land. Player may pick from 1 to 10% exploration rate, and each rate would increasingly cause higher exploration cost per land unit. Low levels of exploration would be very affordable and guaranteed to provide some land source for the Universe to grow.
