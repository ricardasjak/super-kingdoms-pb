## Game states (Server mode)

1. `newbiemode` - Server is in newbie mode.
    - game enters this mode as soon as new round is started
    - lasts for not less than 72 hours (can be configured) but always until next days' 16:00 UTC time
    - game ticks not happening
2. `pve` - Server is in PvE mode.
    - all players who have completed their newbie mode are moved to their kingdom mode `kd-pvemode`
    - `bot-raider` kingdoms are spawned when we enter this mode
    - lasts 72 hours (can be configured)
3. `pvp` - Server is in PvP mode.
    - all players who have completed their newbie mode are moved to their kingdom mode `kd-pvemode` first
    - all players who completed PvE mode (kd-pvemode) are moved to `kd-pvpmode`
    - (skip for now) ai kingdoms (`bot-ai`) are spawned, they share associated player kingdom stats with random -10% to +10% deviation across all stats, same planet type and same race.
4. `paused` - Server ticks are paused, all other actions are possible
5. `gameover` - Game ends after 50 days since `pvp` started, at 16:00 UTC time
    - game scores archived (top100 land, nw, and largest alliances by nw), when entered
    - no any in-game action possible, except new kd creation and actions in `kd-newbiemode`
    - kd's can't enter kd-pvemode
    - no ticks
