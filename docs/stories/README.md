# User Stories & Feature Narratives

This folder contains human-friendly user stories, feature narratives, and gameplay concepts before they are formalized into system requirements.

## Workflow

1. **User Input / Story Creation**:
   - Write stories here describing features, user perspectives, gameplay journeys, and rules in natural, human-readable language (e.g. `<topic>.story.md`).
2. **Requirements Conversion**:
   - The AI agent reviews the stories and formalizes them into precise requirements in [../requirements/](../requirements/) using the standard "shall" / "shall not" phrasing with stable requirement IDs (`REQ-<topic>-<nnn>`).
3. **Tracking & Implementation**:
   - Once requirements are formalized, tasks are tracked in [../TODO.md](../TODO.md) and scheduled for implementation.
