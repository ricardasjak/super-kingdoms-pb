## Kingdom creation

Authenticated user after logging can create a kingdom (kd) by providing the following information:
- kingdom name: string
- planet type: string (predefined list, user selects one)
- race: string (predefined list, user selects one)


The kingdoms should be created on the globe at random positions. 
The game state doesn't impact kd creation, player can create a kd at any time.

Player must provide information for other 5 bot `bot-ai` kingdoms on creation. 
All fields must be pre-populated with random values based on the 12 governor bot profiles.
All these options should be collapsed, not to overload new player choises. This feature is relevant for game experts.
