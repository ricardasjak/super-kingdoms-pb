## Kingdom modes

1. Newbie mode (`kd-newbiemode`) (8 steps, each step executes 16 ticks, ticked manually)
    - newly created kd enters this mode right away
    - can reset if Server mode is `newbiemode` or if newbie mode isn't completed
    - cannot attack others
    - cannot be attacked by others
2. PvE mode (`kd-pvemode`)
    - 72 ticks, ticked automatically by the server, can self tick to catch up with server ticks (one by one).
    - can attack or be attacked by `bot-raider` kingdoms
    - cannot attack or be attacked by other player kingdoms
3. PvP mode (`kd-pvpmode`)
    - ticked automatically by the server
    - can self tick only once per server tick to catch up with server ticks)
4. Dead mode (`kd-dead`)
    - no ticks, nobody can interact with dead kingdom
    - doesn't advance in ticks, it's frozen
    - Kingdom dies when its population reaches 0 population or 0 land.
5. Inactive mode (`kd-inactive`)
    - Kingdom becomes inactive when its owner doesn't login for 72 hours
6. Raider Bot (`bot-raider`)
    - "brainless" kingdom controlled by the game, which spawns random attacks on player kingdoms (PvE mode)
    - it doesn't consider target defense, so many attacks will fail
    - it grows and evolves just like a normal kingdom with autobuilder activated
7. AI kingdoms (`bot-ai`)
    - smart kingdoms controlled by the game that mimic real player behaviors
    - calculate target defense and scout with probes before attacking
    - can attack and be attacked by both players and other bots
    - placed in PvP sectors with real players, participating in sector defense and alliances
    - can accept player bounties to launch coordinated strikes
    - use realistic names and pacing, making them hard to distinguish from real players
