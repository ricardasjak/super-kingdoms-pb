## Newbie mode

Every newly created kd has to pass newbie mode, which consists of 8 steps.
Kingdom is created in `kd-newbiemode` mode.

Player has to complete these steps manually by clicking "tick" button. 
One tick advances the kd by one step (16 ticks total).

Auto build is not available during newbie mode.

At any point during newbie mode, player can reset their kd to creation state, with new race and planet type. 


Every step costs 16 ticks. So 8 steps = 128 ticks.

### Fresh kingdom initial stats:

Main
- land: 250
- population: 2250
- money: 300_000
- energy: 20_000
- soldiers: 200
- scientists: 0
- other units: 0

Buildings
- 80 residences
- 30 star mines
- 30 power plants
- 10 barracks
- 10 probe factories
rest is free land

Other settings
- auto exploration is set to the highest level

### Step execution
- newbie mode contains 8 steps
- each step executes 16 game ticks for selected kingdom
- military units production is queued into 16 ticks
- buildings construction is queued into 16 ticks
- exploration is executed on each tick, when there is multiple of 24 land available to explore (24, 48, 72, etc)
See tick execution story for more details - all tick execution mechanics is the same as regular ticks

### Last step
- we must ensure that player has some military (defensive units) in the queue
- prevent last step execution if there is no defensive points accumulated to 8000 pts (with the queue combined)
- if the last step is prevented - show nice message and suggest to reset newbie mode or order more units


### Other requirements
- Nobody can attack kingdom which is in the newbie mode
- If player tries to reset their kd, the game should ask for confirmation via dialog.
- If the player wants to reset their kd - offer planet type and race selection

### Last step completion
- When game state is in any state except `in-progress` mode, player doesn't advance to PvE mode after the last step
    - Player can still reset and retick Newbie mode
    - Player can just wait, till game state changes to in-progress mode
- When game state is `in-progress` mode, player advances to PvE mode after the last step
- When game state changes to `in-progress` mode, all players who have completed the last step switch to pve mode
