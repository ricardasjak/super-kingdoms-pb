## PvE - player vs environment mode

- This mode lasts 3 days (72 hours)
- Player (kingdom) is still protected from outside attacks during this mode.
- Kingdom advances via server driven ticks.
- Kingdom can speed up ticks only if they left newbie mode when the game is already in-progress mode
- Auto-build is not available in this mode.

## Attacking other kingdoms (bots)
- KD can attack other KDs (only bots) as soon as they leave the newbie mode.
- General Attacking mechanics apply, war leaders take time to return home.

## Catch up mechanism
- If game state `pve` hasnt ended yet, player should be able to force self ticks to fully catch up.
- So player can sign up late and fully catch up if `pve` hasn ended it.
- If server already is in `pvp` mode, newly signed kingdom can partially catch up:
    - fully self tick `kd-newbiemode` (as usual)
    - force 72 hours of PvE mode ticks to reach 072:00:00
    - allow to self tick one time on every server tick, until player's kd catch up with server tick counter.
