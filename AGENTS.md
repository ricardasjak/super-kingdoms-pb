# Super Kingdoms — Agent Guide

This project is a **React SPA (Vite + TypeScript) + PocketBase backend** game application.

## ⚡ Read Before Acting

> Do NOT make assumptions about PocketBase setup, file structure, hook patterns, migrations, or deployment.
> Read the relevant section of `docs/ARCHITECTURE.md` first.

## Key Rules (Always Apply)

1. **File naming**: kebab-case with dot notation — `home.page.tsx`, `use-auth.hook.ts`, `attack.pb.js`. No PascalCase filenames.
2. **Hook files** (`pb/pb_hooks/`): plain `.pb.js` only. No TypeScript. No imports. All globals (`$app`, `routerAdd`, etc.) are injected by PocketBase runtime.
3. **Handler scope**: variables declared outside a handler are NOT visible inside it. Use `require(\`${__hooks}/utils/file.js\`)` inside the handler to share code.
4. **Never touch** `pb/pb_data/`, `pb_prod_data/`, or `pb_test_data/` directly. Never commit them.
5. **After any schema change**: run `npm run gen:types` and commit the updated `src/types/pb.model.ts`.
6. **`pb/pb_public/`** is gitignored — always regenerated by `npm run build`.
7. **Migrations** in `pb/pb_migrations/` ARE committed. Filename prefix must be a Unix timestamp in seconds.
